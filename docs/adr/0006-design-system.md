# ADR-0006: frontend のデザインを DESIGN.md のトークンで統一する

- ステータス: Accepted
- 日付: 2026-10-30

## コンテキスト

AI エージェントに UI を任せると、毎回色や余白がばらばらになり、見た目の質が安定しなかった。
デザインの判断を、エージェントが読める形でリポジトリに置いておく必要がある。

## 決定

- `frontend/DESIGN.md`（温かいクリーム地、セリフ体の見出し、コーラルのアクセント、ダークな面）を唯一のデザイン定義とする。
- DESIGN.md の YAML トークンを `src/styles/tokens.css` の CSS 変数にそのまま写し、コンポーネントからは変数とクラスだけを使う（16進数の色を直接書かない）。
- DESIGN.md をこのアプリに合わせて読み替えた点（ロゴを使わないこと、フォントの代替、余白、グラフの色）は `frontend/CLAUDE.md` に書き、AI エージェントが UI を作る前に必ず読むようにする。
- グラフの系列色は、色覚多様性に配慮した検証ツールで確認してから決める。

## 結果（トレードオフ）

- 良い点: 誰が（どのエージェントが）書いても同じ見た目になる。変更はトークンの1か所で済む。
- 注意点: DESIGN.md はもともと別ブランド（Anthropic の Claude サイト）を分析したもの。ロゴやブランド名は使わず、見た目の言語だけを借りる。
- 注意点: ダークテーマは定義されていないので、必要になったら DESIGN.md を拡張する。
