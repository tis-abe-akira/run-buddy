# frontend: rules for AI agents

## Design: always follow DESIGN.md

UI work must follow [DESIGN.md](DESIGN.md). Do not invent colors, sizes, radii or spacing.

- Use the CSS variables in `src/styles/tokens.css` (they mirror the DESIGN.md YAML keys, e.g.
  `colors.surface-card` → `--color-surface-card`). Never write raw hex values in components.
- Reuse the component classes in `src/styles/global.css`, which map to DESIGN.md components:

  | DESIGN.md component | class |
  |---|---|
  | `button-primary` / `button-secondary` / `button-icon-circular` | `.button .button-primary` / `.button .button-secondary` / `.button-icon` |
  | `feature-card` (cream) | `.feature-card` |
  | `model-comparison-card` (canvas + hairline) | `.outline-card` |
  | `product-mockup-card-dark` | `.dark-card` |
  | `callout-card-coral` | `.callout-coral` (button inside: `.button .button-on-coral`) |
  | `text-input` / `text-input-focused` | `.text-input` |
  | `badge-pill` / `badge-coral` | `.badge-pill` / `.badge-coral` |
  | `category-tab-active` | `.nav-link[data-status='active']` |
  | `top-nav` / `footer` | `.top-nav` / `.footer` |

- Page rhythm: alternate surfaces and never put the same surface mode in two consecutive bands
  (cream → cream-card → canvas+hairline → dark → coral → dark footer, as on the dashboard).
- Coral is scarce: primary buttons, the coral callout, and the "actual" chart series only.
- Headings use `.display-*` (serif, weight never bold). Body and UI text use the sans.
- Numbers: add `.numeric` (lining, tabular figures). Cormorant's default old-style figures make
  "10" read as "Io".

## run-buddy adaptations of DESIGN.md

DESIGN.md describes Anthropic's Claude site. We borrow its visual language, not its brand:

- **No Anthropic spike-mark, no "Claude"/"Anthropic" wordmark.** run-buddy has its own mark
  (`src/components/Wordmark.tsx`).
- **Fonts** (Copernicus and StyreneB are licensed and unavailable): display = Cormorant Garamond
  500 with Shippori Mincho for Japanese; sans = Inter with Noto Sans JP; mono = JetBrains Mono.
- **Band spacing**: this is an app, not a marketing page, so bands use `--spacing-xxl` (48px)
  instead of `--spacing-section` (96px).
- **Charts**: actual = `--chart-actual` (coral), planned = `--chart-planned` (deep teal, dashed).
  Both were checked with a colorblind-safety validator; keep the dash and the direct labels,
  because color alone is not enough to tell them apart.
- Only the light theme exists; DESIGN.md defines no dark theme.

## Code

- Routes (`src/routes`) fetch data with TanStack Query and pass it to components.
  Components in `src/components` take props only, so they can be tested without a network.
- API types come from the backend's OpenAPI spec: start the backend, then run `npm run gen:api`.
  Do not edit `src/api/schema.gen.ts` by hand.
- `src/routeTree.gen.ts` is generated by the TanStack Router plugin on `vite`/`vite build`.
- Run `npm run typecheck` and `npm test` before committing.
